# Formal Classification
- 3 elements:
	- style of wine
		- e.g. Still Red Table Wine
		- e.g. Brut White Sparkling Wine
	- [[Regulatory System]] the wine was made uner
		- e.g. [[BC-VQA|BC-Vintners Quality Alliance]], [[Appellation d'Origine Contrôlée]], [[Qualitätswein]], [[grand cru classé]], etc
	- Processing considerations
		- could be none
		- e.g. [[Champagne Winemaking Steps|Methode traditionnelle]], estate-bottled, single vineyard designation, etc
