# Impossible 4 Criteria
- for a yes/no semantic analysis question, no analyzer can exist that achieves all 4 of these criteria for all input programs
1. is fully automatic (no user input/interaction other than the program)
2. always terminates (the analysis itself, not the program being analysed)
3. on termination: always says "yes" when the answer should be "yes"
4. on termination: always says "no" when the answer should be "no"
